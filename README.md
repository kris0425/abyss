# Discord Roguelike Bot

一個同時支援 Discord 與瀏覽器的輕量 roguelike。兩個介面共用職業、探索、戰鬥、裝備、商店、釣魚與出航規則。

## 網頁版

啟動機器人後開啟 `http://localhost:3000`，即可直接在瀏覽器建立角色並遊玩。網頁版目前包含：

- 職業、開局祝福與地下城／夜城地圖選擇。
- 探索、攻擊、防禦、隱藏房間與五十層通關流程。
- 背包道具、數量購物、武器裝備、釣魚、船塢與出航。
- 桌面與手機響應式介面，並直接使用現有角色、敵人及武器動畫。
- 以瀏覽器 Cookie 保存獨立玩家身分，不會覆蓋 Discord 玩家存檔。

## 目前玩法

- `/start`：選職業並開始新冒險。
- `/status`：查看自己的 HP、層數、金幣、遺物。
- `/help`：查看玩法。
- `/shop`：打開商店，用金幣購買道具、攻防、最大生命或隨機遺物。
- `/items`：查看並使用背包道具。
- `/worldboss`：備用的雷暴骨龍活動查詢指令；玩家也能直接從公告或冒險面板進入。
- `/dashboard`：取得本機圖形化介面網址。
- 按鈕互動：探索、休息、商店、狀態、撤退。
- 冒險面板會公開在頻道，探索、休息、購買和撤退結果所有人都看得見。
- 遭遇敵人時會進入戰鬥狀態，玩家可選擇攻擊或防禦。
- 每個職業會獲得一把初始武器，冒險開始前可選攻擊、血量或幸運祝福。

探索事件包含：

- 戰鬥：敵人會隨層數變強。
- 戰鬥中按 `⚔️ 攻擊` 會造成傷害並承受反擊，按 `🛡️ 防禦` 會大幅降低本回合傷害。
- 戰鬥訊息會顯示敵人模樣，攻擊與防禦回合也會持續顯示。
- 敵人圖片會以戰鬥圖卡顯示在 Embed 裡。
- 敵人反擊傷害已調低，前期比較不會突然暴斃。
- 寶箱：拿金幣，有機會掉遺物。
- 祭壇：花錢強化或回血。
- 休息：固定消耗 3 金幣。
- 陷阱：扣血，可能直接結束本輪。

## 安裝

需要 Node.js 18 或以上。

```bash
npm install
```

複製 `.env.example` 成 `.env`，填入：

```env
DISCORD_TOKEN=你的機器人 token
CLIENT_ID=你的 application client id
GUILD_ID=你的測試伺服器 id
DASHBOARD_PORT=3000
WORLD_BOSS_CHANNEL_ID=世界Boss公告頻道ID（可不填）
```

註冊 slash commands：

```bash
npm run register
```

啟動：

```bash
npm start
```

啟動後會同時開啟網頁遊戲：

```text
http://localhost:3000
```

只啟動網頁版、不登入 Discord：

```bash
npm run web
```

同一個 Node.js 程序會同時維持 Discord 機器人與網頁遊戲 API。

## Discord Developer Portal 設定

1. 到 Discord Developer Portal 建立 Application。
2. 在 Bot 頁面建立 bot，複製 token 到 `.env`。
3. 在 OAuth2 URL Generator 勾選 `bot` 和 `applications.commands`。
4. Bot 權限至少需要 `Send Messages`、`Use Slash Commands`、`Embed Links`。
5. 用產生的邀請連結把 bot 加進你的伺服器。

## 可擴充方向

- 加排行榜：紀錄最高層數、擊殺數、金幣。
- 加多人事件：同頻道玩家一起打 Boss。
- 加每日種子：每天固定地城路線，方便群友比拚。
- 加商店：用金幣買補品或遺物。
- 加職業技能：例如刀客格擋、咒術師爆擊、賭命賊重骰事件。

## 道具與武器

- 商店購買的小紅藥、地城便當、裂片炸彈、煙霧彈會放入背包。
- 背包道具可用 `🎒 背包` 或 `/items` 使用。
- 擊敗敵人有 35% 機率掉落武器。
- 武器品質：普通、稀有、史詩、傳奇。
- 品質決定攻擊力，史詩以上會隨機附加中毒、流血、灼燒、吸血、破甲等效果。

## 地下城頭目

- 每 5 層會遭遇 Boss。
- Boss 名稱包含：慣老闆、雷同事、難搞的客戶、hAO。
- 擊敗 Boss 可獲得大量金幣、遺物，以及保底史詩以上武器。
- 第 10、20、30... 層會遇到 hAO。
- 擊敗 hAO 可獲得專屬遺物「女僕照」：攻擊 +10、防禦 +10，接下來 3 回合每回合回血 3 點。

## 世界 Boss

- 雷暴骨龍每天台灣時間 11:00 與 19:00 現身，每次活動持續 1 小時。
- 玩家可直接按公告或冒險面板的「世界 Boss」按鈕加入，不需要先輸入指令。
- 玩家可以選擇加入全服隊伍，或開啟自己的單人挑戰。
- 出場公告會播放 MP4 動畫；若 Discord 無法上傳影片，會自動改用靜態圖片。
- 組隊與單人擊敗都會獲得金幣、魚餌與永久幸運獎勵。
- `WORLD_BOSS_CHANNEL_ID` 預設為 `🍵｜自由大廳`；送出失敗時會每分鐘重新嘗試，不會直接跳過該場活動。
